# Тайна волшебной галереи

Браузерная игра: 15 предложений и 8 героев, одна непрерывная последовательность без залов.

При открытии показываются правила на пергаменте. Кнопка «Начать игру» запускает новую случайную последовательность. Выберите героя и нажмите на картину либо перетащите его в раму. После правильного ответа предложение исчезает, картина оживает, кнопка «Далее» открывает следующую картину. После последнего ответа анимация показывается четыре секунды, затем появляется «Ты отлично справился! Хочешь ещё?».

«Да, ещё!» перемешивает задания и начинает новую игру. «Пока нет» возвращает к правилам. При повторном открытии сайта всегда показываются правила; старые сохранения версии с залами не используются. Музыки, счётчиков, названия слева сверху и промежуточных экранов залов нет.

Игра: https://propodgotovkaa-creator.github.io/kartina/?v=9

Статические HTML/CSS/JS без сборки. `art.js` анимирует растровые рисунки в Canvas. Иллюстрации и промпты описаны в `ARTWORK.md`. Восемь исправленных сцен используют последовательности цельных поз; их просмотр с паузой и замедлением доступен в `animation-review.html`.

Локально: `python3 -m http.server 4287` из этой папки.
Проверки: `node tests/game.cjs` и `node tests/animation.cjs`.

Проверены правила, все 15 последовательных ответов, исчезновение текста, автоматический финал, повтор игры и перемешивание.
