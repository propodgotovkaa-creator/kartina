# Тайна волшебной галереи
Пробная версия для согласования: три задания, рисованные персонажи и резные рамы на стене замка. Без музыки и звуков.

Управление: перетащить карточку в раму или нажать карточку, затем раму. Клавиатура: Tab, Enter/пробел. Прогресс сохраняется локально; сброс через кнопку ↺. После трёх заданий — просмотр одновременно анимированных картин, увеличение по нажатию. Неправильный ответ не продвигает игру.

Графика: оригинальные растровые иллюстрации, созданные встроенным imagegen. Персонажи собраны из отдельных рисованных слоёв и анимированы через Canvas: рука с ложкой, крылья совы, туловище дракона. Все иллюстрации находятся в assets (WebP). Сова кремово-коричневая, дракон зелёный, ведьма в сливовом наряде. SVG-персонажей нет. Под картиной — три отдельных героя без предметов; предложение на светлой плашке.

Статический сайт без внешних библиотек, шрифтов, аналитики. Финальная интеграция с Genially и остальные 12 сцен не входят в эту пробную версию.

Проверено в браузере: неправильный ответ, перетаскивание, выбор нажатием, клавиатурный ответ, три задания и галерея. После замены графики визуально проверены галерея и крупная картина ведьмы. Повторная проверка на узком экране не завершена: управление браузером отключено в Work.
